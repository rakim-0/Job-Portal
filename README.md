# Job Portal Application

This is a full-stack job portal application where users can register, search for jobs, apply, and manage their job history. It consists of a **React-based frontend** and a **Node.js/Express** backend.

## Technologies Used

### Frontend:
- React
- Redux
- Axios
- MUI (Material UI)
- React Google Charts

### Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT for authentication

### Others:
- bcrypt for password hashing
- Cookie-based authentication
- dotenv for environment variables
- Morgan for logging
