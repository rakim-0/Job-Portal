# Job Portal Application

This is a full-stack job portal application where users can register, search for jobs, apply, and manage their job history. It consists of a **React-based frontend** and a **Node.js/Express** backend.

## Table of Contents

- [Technologies Used](#technologies-used)
- [Installation](#installation)
- [Features](#features)

## Technologies Used

### Frontend:
- React
- Redux
- Axios
- MUI (Material UI)
- React Google Charts

### Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT for authentication

### Others:
- bcrypt for password hashing
- Cookie-based authentication
- dotenv for environment variables
- Morgan for logging

## Features

### Users:
- Sign up, sign in, and log out functionality.
- View and update their profile.
- Apply for jobs and manage job application history.

### Admin:
- Manage job postings (create, edit, delete).
- View all registered users.
- View job applications.
